# Alpha POS

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Restaurant administration: understand sales, manage orders and customers, operate
shifts, and maintain the menu, inventory, team, and finances. The current code and
the user-provided AGENTS.md are the factual source for available capabilities.

## Capabilities and Constraints

Preserve existing API contracts, information, filters, actions, and permissions.
The dashboard is one continuous page with five reporting sections. Start and end
dates each have a custom date-and-time picker. Today's order count is independent
of the selected reporting period. Real backend data and honest unavailable states
are mandatory. The AI assistant answers restaurant questions using existing APIs.
Backend ownership is external; frontend work must not change that repository.

## Brand Commitments

Alpha POS. The September 9 user reference adds a legacy-inspired navy/blue palette,
colorful analytical charts and compact reporting tables. Blue is the default;
the earlier approved forest, sage, and ivory palette remains selectable. Preserve
the established typography. The user requests substantially clearer layouts, modern
custom controls and icons, restrained smooth motion, and comfortable daily use.

## Accessibility & Inclusion

Support Uzbek, Russian, and English; light and dark themes; desktop and mobile;
keyboard navigation, visible focus, reduced motion, and readable long labels.

## Evidence on Hand

`AGENTS.md`, `docs/design-system.md`, current Vue application, and the user's
screenshots and feedback. Test fixtures are isolated from live application data.
